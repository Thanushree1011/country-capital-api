# WhatsApp Notification Feature

## Overview

This document describes a proposed WhatsApp notification feature for the Country Capital API project.

## Purpose

The feature aims to provide users with optional WhatsApp notifications for important updates.

## Planned Features

* Allow users to opt in to WhatsApp notifications.
* Store the user's WhatsApp number when provided.
* Keep existing email notifications unchanged.
* Allow users to disable WhatsApp notifications at any time.
